यह Open Logic Project के 11 स्वीकृत खंडों का मशीन-सहायित हिन्दी संचयी
अनुवाद है। हर खंड का TeX PDF में सफलतापूर्वक बनाया गया, गणितीय और औपचारिक
संरचना की जाँच हुई, और हर rendered page को मूल detail पर देखा गया। मुख्य
17-page reader भी अलग से build, search, render और page-by-page inspect किया
गया है।

यह अभी पूरे Open Logic corpus का अनुवाद नहीं है। मानव समीक्षा, peer review,
critical edition या PDF/UA certification का दावा नहीं किया जाता। मानव समीक्षा
स्वागतयोग्य है, पर production gate नहीं है। अगला सटीक स्रोत
`content/sets-functions-relations/relations/trees.tex` (`sfr/rel/tre`) है।

## Repository map

- `reader/`: current cumulative reader, front and centre
- `source/`: editable Hindi overlay and pinned OFL Devanagari font
- `build/`: reproducible build instructions and entry point
- `evidence/`: concise source/coverage/QA/DataCite state
- release assets: complete relevant decisions, rejections, terminology,
  provenance logbooks, unit QA, rejected builds/renders, and hashes

Stable identifiers apply to the maintained Hindi work lineage. Individual
translation units do not receive separate DOIs.
